## The entry (142 characters, python-verified)

> The doormat says WELCOME in faded letters, has been stepped on ten thousand times, and has never once been thanked — a doormat in every sense.

## How it works

`main.ts` (Node standard library only, no network) writes the one-line review to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing
newline. Run it with `npx tsx main.ts` or compile with `tsc` and run the output
with `node`.

See [candidates.md](candidates.md) for the 8 candidates, their scores against
the judge's five criteria, and the two rounds of iteration that produced the final line.
